# Backend Data Siswa

## Instalasi
1. `npm install`
2. Salin `.env.example` menjadi `.env`
3. Sesuaikan konfigurasi MySQL.
4. Jalankan `database.sql` di MySQL/phpMyAdmin.
5. Jalankan `npm run dev` atau `npm start`.

## Endpoint
- GET `/api/siswa`
- GET `/api/siswa/:id`
- POST `/api/siswa`
- PUT `/api/siswa/:id`
- DELETE `/api/siswa/:id`
